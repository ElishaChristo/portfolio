# Portfolio Website

This is a Vite + React portfolio for Elisha JJ Christo.

## Run locally

```powershell
cd 'C:\Users\Reaper\OneDrive\Desktop\web developer tools\portfolio'
npm install
npm run dev
```

## Build

```powershell
npm run build
```

## Preview the production build

```powershell
npm run preview
```

## Notes

- The site is built with React and Vite.
- The main content is in `src/App.jsx`.
- Customize your skills, projects, and contact details there.
